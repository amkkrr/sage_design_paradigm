## 2. 提取方法

1. **共性保留**：主题值、数字层级、容器、网格、卡片、基础控件、Seg运动语言。
2. **差异参数化**：卡片数量、KPI业务、分页、单位、时区、图形尺寸与容量。
3. **单项目组件可选化**：日期/趋势/热力、矩形图/面包屑/详情/规划均为可选模式。
4. **业务内容移出核心**：路径、应用名、计算公式、采集命令、服务端口、固定阈值与存储key不做通用默认。
5. **局限不标准化**：已知溢出、键盘缺口、读屏关联缺失或请求竞态改为接入时的检查要求。
6. **实现与要求分开**：通用文档是未来项目的规范参考，不是声明存在已实现的通用组件库。

## 4. 差异与取舍

| 议题 | 来源差异 | 本仓库决定 |
|---|---|---|
| 数据模式 | 在线统计查询 vs 内嵌磁盘快照 | 刷新方式由项目声明，静态模式不假加载 |
| 卡片数量 | 6 vs 7 | 不固定数量 |
| KPI | 随度量重排 vs 固定主指标/单位切换 | 共享视觉，业务顺序可配置 |
| 主指标修饰 | 26px币种 vs 24px容量单位 | 默认24–26范围，按内容选取 |
| 顶栏gap | 14 vs 8 | 使用8–14密度范围 |
| 页脚/说明行高 | 1.7 vs 1.9等 | 采用范围，不伪称完全一致 |
| 表格 | 12列/50行 vs 6列/12项 | 不固定列数、分页和行高 |
| 图形 | SVG趋势/热力 vs HTML矩形图 | 可选模式，不强制图表库或DOM技术 |
| 排行归一化 | 各自实现不同，磁盘聚合项可能超长 | 聚合后校验最大值、分母与溢出 |
| 搜索语义 | combobox/listbox vs dialog+原生按钮 | 二选一并实现完整相应键盘行为 |
| 时间 | 本地时间 vs 保留采集offset | 项目显式选择，禁止混用隐含规则 |
| 分类映射 | 应用/模型 vs 路径 | 移除实体名，使用稳定ID契约 |
| Tooltip | 80ms淡入 vs 无过渡；边界处理不同 | 动画可选，要求处理长内容和视口边界 |
| Loading | 异步透明度 vs 无异步数据 | 仅真实异步操作启用 |
| reduced-motion | 两者主要处理Seg | 通用要求评估所有新增非必要动画 |
| 状态warning | 已定义但未使用 | 可选token，存在不等于已实现预警 |
| 无障碍缺口 | 排序语义/图形键盘/提示关联等 | 明确为接入要求，不照搬缺陷 |
| 来源安全边界 | 请求统计/文件路径各有敏感信息 | 不发布原始数据，不自动继承可公开假设 |

## 5. 交付与验证边界

本仓库交付四份 Markdown 与一份 JSON。没有复制来源项目的原始数据、截图、完整源文档、字体文件或代码。来源绝对路径仅存在于本说明的追溯信息中。

本次文档级验证涵盖：JSON可解析、相对文件链接存在、共享调色板与输入JSON对应、关键布局与动效数值一致、无行尾空白，以及提交前的 `git diff --check`。

未声称完成：通用组件运行验证、视觉截图对比、WCAG认证、全浏览器/字体一致性、完整读屏测试。新增“要求”不能写成来源“已实现事实”。目标项目必须自行验收。
