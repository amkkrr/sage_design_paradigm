## 1. 审计结论

**PASS：作为可选视觉规范与独立模拟示例，可以提交 PR。**

原包不能直接认定与基线全面一致：存在深色回退缺失、默认尺寸漂移、石纹下对比度下降、图表精确值和数据口径不足等问题。以下发现已修正并复验，没有保留本次交付范围内的 Critical / High / Major 未闭环问题。

原 `tokens/design-tokens.json` 与 v1.0.0 提交 `8fd7d2de97d508cc030be289ea33d92cc7835645` **深比较，仅 version 从 1.0.0 变为 1.1.0**。原主题、排版、布局、组件、动效、层级和项目契约全部未变。Ash 是显式 opt-in，不是替换 Sage 默认主题。

本结论**不是**生产应用验收、全组件实现证明、实际字体加载验证或 WCAG 认证。未采用的可选模块与尚未实测的能力见覆盖矩阵和残余风险；N/A 不是“默认通过”。

## 2. 审计发现与闭环

### E-1：有效深色没有基线变量和完整回退

**原级别**：Major；**状态**：已解决。

**原问题**：原 HTML 仅演示两种浅色调和材质；recipe 期望宿主提供基线，却没有配套宿主。强行设置 dark 后 `--page` 为空、卡片底色透明，不能作为“双主题不变”的实现证据。

**修复位置**：`examples/ash-marble-demo.css:1`、`examples/ash-marble-demo.js:26`、`docs/ASH_MARBLE.md` 第 2 节。

**修复与复验**：示例提供原 Sage light/dark 基线，显式实现 auto/light/dark 循环、系统偏好与手动优先、首帧解析和存储恢复。Ash 深色关闭材质，主 KPI 与数据色回归原 Sage。所有 48 个状态组合实测，并对照 JSON 检查全部示例基础颜色。

### F-1：原纯色 token 检查遗漏纹理后的实际背景

**原级别**：Major；**状态**：已解决。

**原问题**：原检查只计算文字对 page/surface-1 的纯色对比度。苍白板的 `ink-3` 在最强单条石脉 + 原 opacity0.38 上降至约 **4.47:1**，低于 4.5:1 的正文检查线。

**修复位置**：`examples/ash-marble.css:78`、`tokens/ash-marble.json` 的 material、`scripts/validate_ash_marble.py:148`。

**修复与复验**：透明度同步降至 **0.12**；检查所有 SVG path 完全重叠时的保守 alpha 上界，并向下取整背景色以避免有利舍入。苍白、苍灰的最低文字比值分别为 **4.508:1 / 4.845:1**。同时检查主强调文字与控件纯色底，限定当前 SVG 结构，素材变化必须重新审查。该检查不覆盖所有语义色、图表色、浏览器渲染或宿主组件。

### D-1：图表、指标与时间范围缺乏闭合数据契约

**原级别**：Major；**状态**：已解决。

**原问题**：原趋势写“最近30天”却有16组柱，柱高和 KPI 无共同数据源，缺少精确值表格、明确时区及可核对的分母；增长值没有与两期数据闭合。

**修复位置**：`examples/ash-marble-demo.js:67`、`examples/ash-marble-demo.js:98`、`examples/ash-marble-demo.html:82`、`docs/ASH_MARBLE.md` 第 6 节。

**修复与复验**：改为七组 UTC 对应自然日，共享固定模拟样本；本期/上期合计128430/114000、增长12.7%、成功127402/128430=99.2%。四类互斥完整且总和128430；M 明确为1000000。日明细、分类计数、精度、分母和模拟快照可见。柱高按真实模拟整数和25000零基线上限计算，轴刻度按比例定位，核对总数、占比、柱高和刻度位置。

### E-2：默认布局、组件与数字层级漂移未登记

**原级别**：Medium；**状态**：已解决。

**原问题**：原包主数字48px、页题19px、card padding20/21/17、断点800/480，与其宣称继承基线的尺寸不一致。

**修复位置**：`examples/ash-marble-demo.css:69`、`examples/ash-marble-demo.css:80`、`examples/ash-marble-demo.css:114`。

**修复与复验**：恢复52/24/17/14层级、1240容器、12列桌面7/5、gap16、card16/18/14、980/600断点、原 Seg/Ghost Button 几何、12px分类横条和2px最短可见宽。四格 KPI 网格明确记作业务数量适配，不补无意义占位。1440px 实测内容1176px、7格卡片约679.33px。

### D-2：伪元素裁切与透明控件会让装饰影响操作

**原级别**：Medium；**状态**：已解决。

**原问题**：原 recipe 的 `overflow:hidden` 可能裁焦点/浮层；仅 `background-image:none` 不能阻止祖先石纹透过透明控件。错误给按钮/提示等加材质 class 也缺少防护；统一把卡片直属子元素改为 position:relative 会覆盖宿主的 fixed/absolute 浮层和原生dialog定位。

**修复位置**：`examples/ash-marble.css:97`、`examples/ash-marble.css:104`。

**修复与复验**：移除卡片内容裁切，仅装饰层沿用圆角；在isolated context内给伪元素z-index:-1和pointer-events:none，不重写宿主子元素定位。嵌套控件、summary、精确表格和对应浮层使用不透明纯色底；常见错误 opt-in 不生成纹理。深色、flat、forced-colors 不显示石纹；浏览器检查嵌套按钮背景、错误 class、伪元素、卡片 overflow，以及fixed浮层/原生dialog定位保持。容器是否“大卡片”仍需语义审查，不能由 class 自动认证。

### D-3：系统变化可能让焦点落在失效控件，强制颜色状态未解释

**原级别**：Medium；**状态**：已解决。

**原问题**：系统从浅色切深色或进入 forced-colors 时，原先聚焦的 tone/material 按钮可能被禁用；只隐藏纹理却继续称其“生效”会混淆用户。

**修复位置**：`examples/ash-marble-demo.js:26`、`examples/ash-marble-demo.js:51`。

**修复与复验**：禁用但保留不生效选择，状态文字说明回退；记录被禁用前的焦点并转到主题按钮，preventScroll，不打断其他正常焦点。自动 mode 删除显式 key，非法/失效存储回退；系统事件检查等待实际状态变化，不靠定时 sleep。验证 Enter/Space、焦点环、系统变化、存储恢复和存储拒绝。

### F-2：精确值、语义与非颜色替代不足

**原级别**：Medium；**状态**：已解决。

**原问题**：原图没有可访问精确表格，泛用 div 上的名称不能替代有效图形语义；选中或期别不应只依赖低对比背景和颜色。脚本失效时按钮也不应伪装可用。

**修复位置**：`examples/ash-marble-demo.html:19`、`examples/ash-marble-demo.html:82`、`examples/ash-marble-demo.html:116`、示例 CSS/JS。

**修复与复验**：原生按钮/summary、命名的 group/region/img、关联说明、表头scope、数值右对齐、Enter/Space展开精确表格、焦点保持和本地横滚。期别有标签和虚/实边框，选中标签有中性下划线；无脚本时指标为“—”、控件禁用并给说明。检查ARIA引用、键盘焦点、表格语义、强制颜色与至少24px的示例交互目标；不是触摸实机或读屏认证。

### E-3：装饰强调色与变化方向语义混用

**原级别**：Medium；**状态**：已解决。

**原问题**：原增长提示使用灰青强调，存在把上涨误读为“好”的风险；还使用全大写 kicker。原数据色只提供 `--data-s*`，基线组件的 `--s*` 映射不完整。

**修复位置**：`examples/ash-marble.css:25`、`examples/ash-marble-demo.js:98`、HTML 和扩展文档。

**修复与复验**：仅主 KPI 使用矿物蓝；变化箭头和解释用中性 ink-3，明确“不表示好坏”；不使用全大写宽字距建立层级。分类ID固定映射，other用专门聚合色；recipe同时提供基线命名及数据色别名，并说明继承的状态/seq/heat需要实际重测。

### F-3：窄屏放大存在固定12列间隙的隐藏溢出

**原级别**：Medium；**状态**：已解决。

**原问题**：正常320px检查不足以证明文本放大可用；200%缩放时12列保留11个间隙，会使内容最小宽度超过可用空间。

**修复位置**：`examples/ash-marble-demo.css:118`、`tests/test_ash_marble_browser.py` 的 stress 检查。

**修复与复验**：≤980px内容卡片网格切单列；长标题/按钮允许换行，大数字在极端放大时不覆盖相邻内容。五种宽度分别检查长文本、CSS整页zoom200%和独立文本字号200%；图形和表格在自身容器滚动，页面整体不溢出。未把这类自动化模拟说成所有浏览器原生缩放或所有语言验证。

### C-1：交付范围与验证声明容易过度解读

**原级别**：Medium；**状态**：已解决。

**原问题**：README继续称不含应用代码，却增加独立示例；字体栈可能被误读成字体已加载；原提取记录没有明确区分后续示例测试和来源项目测试。

**修复位置**：[README](../../README.md)、[来源记录](../EXTRACTION_NOTES.md)、[扩展规范](../ASH_MARBLE.md)。

**修复与复验**：明确交付为规范、参考和独立模拟示例，不是生产应用或组件库；不分发/下载字体，示例实际用fallback。1.0.0来源指纹与验证只属于原提取；1.1.0另记输入与本地证据。新增测试无前端框架/构建依赖，Playwright仅是可选开发检查依赖。

## 5. 残余风险与实施提醒

### R-1：对比度计算和单浏览器示例不能升级为全局认证

**级别**：Advisory。

文字/纹理检查仅针对此处两种浅色板与指定SVG；状态、图表、轻边框和宿主组件须在真实叠层重测。Firefox/WebKit、读屏、触摸实机、原生缩放和软键盘未测。forced-colors/reduced-motion是Chromium媒体模拟，不是所有操作系统实机覆盖。

### R-2：字体栈不是字体文件，不能据此宣称像素复刻

**级别**：Advisory。

本例不下载字体，实际使用本机fallback。Space Grotesk/Noto Sans SC/Space Mono的许可、实际加载、跨平台中文粗细和尺寸必须在目标项目独立验证；没有概念图像素一致承诺。

### R-3：参考overlay不承担业务组件与真实数据契约

**级别**：Advisory。

目标项目仍需填写[适配契约](../ADOPTION_TEMPLATE.md)，包含零/缺失/错误、权限、刷新、聚合/分页、URL、异步旧响应、弹层及焦点等。样本的固定计数与API缺失绝不能当成业务验收覆盖；SVG滤镜性能也需在实际设备评估。

### R-4：新素材、默认值或实现变更使本次判定失效

**级别**：Advisory。

增加纹理透明度、替换SVG/颜色、修改默认主题或组件时，重新运行检查并审查相关条款。新增字体/第三方资产前检查许可；不擅自补开源许可证。后续报告应使用新的审计编号并追踪本次发现，不把此PASS用于未来未审改动。
