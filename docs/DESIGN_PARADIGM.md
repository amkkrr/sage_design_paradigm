# Sage 通用设计范式

> 版本：1.0.0。依据两份项目设计文档提取，不是重新审计来源源码，也不是宣称已有通用组件实现。
>
> **核心**：跨项目维持的设计语言。**默认**：可覆盖的起点，变更需说明。**可选**：按需求接入，不要求所有页面具备。**适配**：必须由业务项目确定。
>
> 来源与差异见 [EXTRACTION_NOTES.md](EXTRACTION_NOTES.md)；机器可读默认值见 [design-tokens.json](../tokens/design-tokens.json)；落地契约见 [ADOPTION_TEMPLATE.md](ADOPTION_TEMPLATE.md)。

## 1. 设计性格与适用范围

**核心**：数据优先、紧凑但有层次、轻边框、低装饰、交互结果可解释。

- 浅色以鼠尾草绿画布和墨绿正文为识别特征；深色使用独立近黑色调色板，而非反转浅色。
- 用数字建立首要层级，不用大型标题 banner 抢占首屏。
- 页头、筛选和 KPI 直接置于画布，分析、图表和明细进入卡片。
- 控件以中性色为主；分类色表达实体身份；语义色表达状态。三者不可混为一谈。
- 细边框和留白承担分组；卡片无投影，不依靠彩色侧条或渐变强调。
- 交互服务于筛选、比较、下钻和解释；没有真实数据或后端能力时，不制造趋势、进度或操作成功。

适用于数据仪表盘、报告、资源/用量分析和内部工具。不直接规定营销页、内容阅读站或复杂编辑器的全部交互。只读是可选应用形态，**不是所有 Sage 应用必须只读**；写操作须另行设计权限、确认和恢复机制。

## 2. 信息架构

**默认页面顺序**：

```text
页头       标题 / 数据范围与更新时间 / 全局操作 / 主题
筛选条     全局上下文 / 条件 / 度量或单位
指标区     一个主指标 + 若干次指标
状态区     可选：数据完整性、异常或采集边界
12列网格   概览 → 分布或趋势 → 解读 → 明细 → 可选规划/方法说明
页脚       来源 / 时间与口径 / 能力边界
浮层       按需：搜索选择、tooltip、详情dialog、短通知
```

- 卡片数量、顺序、KPI 数量由信息结构决定，不固定为六张或七张卡片。
- 主指标表达当前任务最重要的数值；是否随度量切换、是否重排次指标需显式约定。
- 时间、来源、统计范围和完整性不应只隐藏在 tooltip 中。
- 每张卡片围绕一个主要问题组织；解释可与图表并列，但不要为了对齐强行拉伸图形。

## 3. 布局与空间

| 默认参数 | 值 |
|---|---|
| 盒模型 | `border-box` |
| 页面容器 | 居中，max-width 1240px，padding 28px 32px 64px |
| 上限内容宽度 | 1176px，派生值，不是独立固定宽度 |
| 页头 | flex / baseline / space-between / gap16，底部 padding18 + hairline |
| 筛选条 | flex-wrap / gap10 / padding14px 0；sticky top0，z5，page 底色 |
| 尾部度量控件 | `margin-left:auto`，不插入占位 spacer |
| 卡片网格 | `repeat(12,minmax(0,1fr))`，gap16，margin-top20 |
| 常用跨度 | 12 / 7 / 5；6 为可选等分变体 |
| 卡片 | padding 16px 18px 14px，radius8，1px hairline |
| 卡片头 | baseline / space-between / gap12 / margin-bottom10 |
| 页脚 | margin-top28，12px，ink-3，行高1.7–1.9 |

五格 KPI 的默认网格为 `minmax(260px,1.15fr) repeat(4,minmax(0,1fr))`。单元 padding `22px 20px 22px 0`，后续格左 padding20 + 左边框。指标数量不同时重定义网格，不补无意义占位数据。

1176px 内容宽度下，7/5 跨度外宽约679.33/480.67px，默认卡内宽各减38px。这些是盒模型推导，不保证任何字体、滚动条、缩放下像素完全一致。

间距以16–24px主分区节奏为主，允许2/4/6/8/10/12/14px微调；并非严格4px或8px网格。顶栏按钮间距可在8–14px内按密度选择。

## 4. 排版与数字层级

默认正文栈：

```css
font-family: "Space Grotesk", "Noto Sans SC", "Noto Sans CJK SC",
             "PingFang SC", "Microsoft YaHei", sans-serif;
```

默认等宽栈：

```css
font-family: "Space Mono", "Noto Sans SC", "Noto Sans CJK SC",
             ui-monospace, Menlo, Consolas, monospace;
```

| 角色 | 字号/字重 | 行高/字距 | 颜色 |
|---|---|---|---|
| 主指标 | 52/600 | 1.1 / −.02em | ink-1 |
| 次指标 | 24/600 | 1.2 / −.01em | ink-1 |
| 页题 | 17/600 | 1.5 / +.01em | ink-1 |
| 卡片题 | 14/600 | 1.5 | ink-1 |
| 正文 | 14/400 | 1.5 | ink-1 |
| 控件 | 13/400，选中600 | 1.5 | ink-2 → ink-1 |
| 标签/表格 | 12.5，表头500 | 1.5 | ink-2 / ink-3 |
| 说明 | 12–12.5/400 | 1.5–1.8 | ink-3 |
| 坐标/辅助标记 | 11–12/400 | 按图形定位 | ink-3 |
| Tooltip | 12/400，值600 | 1.7–1.8 | 分层使用ink |

- 主指标单位降级为24–26px，次指标单位约13px；前缀/后缀、币种和单位由业务决定。
- 对齐比较的数值、表格数字、坐标与提示值使用 `tabular-nums`；不强制把所有 KPI 变成等宽字体。
- 路径、标识符、精确数值等按需使用 Mono；正文不大面积使用等宽。
- 不使用全大写加宽字距的 kicker 建立层级。
- 字体应本地托管或嵌入，不强制依赖外部字体服务。此仓库只提供字体栈，不提供字体文件或授权保证。
- 中文字重随本机字体变化。来源采用的 Regular/Bold 分档不是跨平台像素一致承诺。

**核心用色规则**：

1. 实体颜色不随排序改变；映射可采用稳定 ID 表或确定性哈希。有限色槽允许冲突，因此仍需标签与形状辅助。
2. 不绑定应用名、供应商或目录名；同一实体在不同图表的映射若不同，必须明确说明。
3. 状态阈值由业务定义。绿色不能暗示所有数据完整或所有操作安全；红色分类不代表错误。
4. 变化方向默认中性箭头，不自动将增长标为好或坏。
5. 常规 hover 用 wash，部分控件可用 axis 边框；不能用 hover 代替键盘焦点。
6. 顺序色阶 `seq-0..7` 用于连续量/meter，`heat-0..7` 用于热力分档，二者独立。完整值见 JSON；零值和缺失值是否同色须由数据契约确定。
7. 本调色板未在本仓库完成逐组件对比度认证。特别是彩色小字、状态图标白描边与半透明叠层，必须在实际背景上验证，不能仅凭 token 存在宣称 WCAG 合规。

表格行高随内容、按钮和字体变化，不硬编码为34px或38px。分页大小、列数、附表高度由项目决定；长表格使用自己的横向滚动容器，而不是让整个页面溢出。

## 7. 分段控件与动效

单选 Seg 使用共享底板作为渐进增强：

- 业务选中态是唯一真源，例如按钮 `aria-pressed`；动效脚本不接管筛选业务。
- 根据选中按钮实际 `offsetLeft/Top/Width/Height` 测量，不假设等宽或固定选项数。
- 初次定位不滑动；无选中项时隐藏底板，允许快捷预设与自定义范围不匹配。
- DOM、尺寸与字体加载变化后重新测量；用 rAF 合并观察器触发。
- 底板 transform/width/height 默认460ms；文字颜色180ms ease，文字不跟随底板移动。
- 首选曲线：`linear(0, 0.48 12%, 0.86 24%, 1.025 38%, 1.04 48%, 1.012 65%, 0.998 82%, 1)`。
- 回退：`cubic-bezier(0.22,1.12,0.36,1)`。
- 数据立即更新，不等待动画；脚本失败时普通选中样式仍可用。
- 分页、操作按钮、多选图例不使用单选滑动底板。

**落地要求**：`prefers-reduced-motion` 至少取消 Seg 位移与文字过渡；新增其他非必要动画时一并评估和关闭。这是通用改进要求，不表示来源实现已经全站处理。

异步加载可选用局部 opacity .55 / 150ms；tooltip 可无动画或80ms淡入。静态页面不显示假加载。不要默认加入骨架、图形变形或主题渐变。

## 8. 可选数据可视化模式

以下是模式选择，不是所有页面必须同时拥有的组件清单。

| 分析问题 | 模式 | 通用约束 | 来源参考参数，非强制 |
|---|---|---|---|
| 随时间变化 | 趋势/堆叠柱 | 时间口径明确，零基线，节制网格，附明细替代 | 图高260，柱宽2–24，峰值/当前时间标注 |
| 类别大小比较 | 横条排行 | 排序、最大值与占比分母清晰，数值不被裁掉 | 高12，前N项+其他 |
| 层级组成 | 矩形图 | 面积比例、下钻语义、极小项替代入口 | 图高272，二分布局，最多8项含聚合 |
| 周期分布 | 热力图 | 说明分档、样本范围、时区；可访问附表 | 7×24仅适合周内小时分布 |
| 整体组成 | 分段容量/比例条 | 分母和各段关系清楚，间隙会影响着色像素 | 高22、gap2 |
| 目标与比例 | Meter/Range | 真实值与假设值分离；目标变化不伪装执行 | meter高8，range范围按业务定义 |
| 精确比较 | 表格/KV | 保留精确值、单位和缺失语义 | 数值tabular，必要时Mono |

### 聚合、排序和归一化

- 为每个图表明确 N 是否包含“其他”。不能用同一个 N 暗指不同容量规则。
- 聚合后重新计算用于条长的最大值，或明确采用另一分母并处理越界；不继承来源排行聚合项可能溢出的缺陷。
- 筛选只影响某张表时，不悄悄改变相关图表或占比的分母。
- 父子数据不可相加为总量；残差、未分类和未采集部分必须区分。
- 最短可见条/柱和间隙会改变实际着色比例；精确数值以标签、tooltip和附表为准。
- 图例若可隐藏序列，应说明是否重算轴、合计和附表；静态图例不伪装成按钮。
- 不同渲染技术均可使用，但可交互图形必须有键盘入口与语义化替代。

## 9. 状态模型与作用范围

每个项目先建立“操作 → 更新区域 → 保留状态 → 重置状态”表，再实现交互。

| 状态层 | 示例 | 通用约束 |
|---|---|---|
| 全局上下文 | 数据源、账户、时间区间 | 明确影响哪些指标与卡片 |
| 全局呈现 | 度量、单位、主题 | 单位切换不应无意改变统计语义 |
| 局部探索 | 下钻、搜索、图例、表格视图 | 明确是否作用于当前层、全数据或单卡片 |
| 局部表格 | 类型、排序、页码 | 过滤/排序变化通常回第一页，边界按钮禁用 |
| 临时交互 | 弹层、tooltip、dialog | 与可分享查询条件分离 |
| 假设状态 | 目标滑块、规划参数 | 不改变真实数据，不暗示已执行操作 |

- 搜索输入与选择提交分离；输入法合成时不截获导航/提交快捷键。
- “清除筛选”“重置”“刷新”是不同动作，必须分别定义。
- URL只记录有分享价值的字段；无效值安全回退。push/replace、后退恢复范围需明确。
- 主题默认循环自动→浅色→深色→自动；项目独立的 localStorage key，自动模式移除显式值。存储失败不应阻断页面。
- 样式加载前可应用已存主题；自动模式跟随系统，手动选择优先。
- 异步统计、明细、排序和翻页均需避免旧响应覆盖新条件。来源局部请求缺少防护的现状不是可复用标准。

## 10. 浮层、提示与焦点

默认层级：sticky筛选5 → tooltip20 → 选择弹层30 → 可选notice40。原生 `dialog.showModal()` 在 top layer，不属于普通 z-index 数列。

### 搜索选择与日期

- 搜索弹层距触发器6px、视口边缘至少8px；翻转并夹取四边，超长内容内部滚动。
- 监听窗口、滚动与 visualViewport 变化；移动软键盘出现后仍应可操作。
- 可选采用非模态 dialog+原生按钮，或完整 combobox/listbox 模式；不得只粘贴 ARIA role 而缺少对应键盘行为。
- 打开聚焦搜索；Escape关闭回焦；外点或焦点离开关闭而不抢夺外部焦点。非模态弹层不锁住 Tab。
- 日期组件是可选模块：验证格式、真实日期和允许范围；浏览月份不等于提交，时区与范围交换策略由项目确定。

### 详情、复制与通知

- 详情可用原生dialog；默认宽540、max-width视口−32、max-height动态视口−48、padding18、radius8。遮罩可用黑色30%，无模糊。
- 提供关闭按钮、Escape和关闭回焦；不可把浏览器原生能力宣称为已完成跨浏览器验证。
- Clipboard Promise 成功后才提示成功；失败提供可选中原文或手动复制入口。
- 通知默认底部24、padding8×14、radius6，约3500ms；重要错误不能仅靠短暂通知。
- Tooltip 同时支持 hover/focus；有需要时用 `aria-describedby` 关联，不把关键数据只放在提示里。
- 超长tooltip需限宽、限高或转详情入口，不能继承只夹取上边/左边的局限。

## 11. 内容与数据契约

每个指标必须声明：名称、来源、单位、公式、分母、筛选范围、时间/时区、精度、零/缺失/无效规则、完整性及刷新方式。

- 默认整数可使用 en-US 千分位、百分比1位；这些是起点，不通用于所有币种、容量或高精度场景。
- 容量必须区分1000与1024，钱款须注明币种；精确值与紧凑值建立对应。
- 数值0不等于缺失；缺失常用“—”并提供原因，不虚构为0。
- 分母为0的百分比可能是0或不可用，必须依据语义决定，不能全局套一个除法助手。
- 当前样本、历史汇总、估算、实测、规划值必须区分，不凭汇总编造细粒度数据。
- 图形无项目不等于真实为空：可能是未采集、权限限制、阈值或深度限制。
- 状态提示注明评价范围，数据完整性与业务健康分开表达。
- 时区策略只能选择并说明，不能同时隐含“保留采集时区”和“浏览器本地时间”。
- 导出明确是完整数据还是当前筛选结果，并说明包含的敏感信息。
- 动态文本使用安全DOM API或正确转义；内嵌JSON需防止脚本标签闭合。主题复用不意味着数据可公开。

## 12. 响应式与系统偏好

| 条件 | 默认行为 |
|---|---|
| >980px | 五格KPI变体、7/5并列卡片、页面左右32 |
| ≤980px | 页padding20/16/48；页头换行；五格KPI首格通栏、其余两列；左分隔改上分隔；卡片通栏 |
| ≤600px | 按内容将卡片工具换行、内部双列改一列、搜索框占满宽度；可将卡片左右padding改14 |
| 任意宽度 | 筛选/图例换行；长路径折行或可恢复全文的省略；表格局部横滚 |
| reduced-motion | 禁用非必要运动，保留明确即时状态反馈 |
| forced-colors | 保证选中、焦点、边框可辨；图表附标签/表格，不只依靠保留色值 |

980/600是默认断点，不是禁止添加断点。不要将趋势图的最小viewBox宽320套到所有图形，也不要将固定374px热力图套到任意类别矩阵。

至少在1440、980、600、390、320px视口检查；再验证文本缩放、长标题、长标识符及大量选项。桌面紧凑尺寸不等于触摸可达性：小图元应有足够大的替代操作入口。

## 13. 可访问性落地要求

以下是接入验收要求，**不表示两份来源已经全部实现或验证**：

- 优先原生按钮、input、range、details和dialog，所有控件有可理解名称。
- focus-visible默认2px focus、offset2；不能仅删除outline而不提供替代。
- 分段选中、禁用、展开、当前路径和meter状态有相应语义。
- 表头使用scope；`aria-sort`放在对应th上，而不是排序按钮上。
- 可点击图形支持Enter/Space，或提供等价原生按钮；不是只设置tabindex。
- 导航、局部重绘和关闭浮层后焦点可预测；模态与非模态焦点策略明确。
- 状态更新使用合适的status；需要立即处理的错误才使用alert，避免读屏噪声。
- 颜色不是唯一编码；必要时提供可访问附表和精确值。
- 验证实际主题下文字/控件对比度、键盘全流程、减少动画与强制颜色；记录读屏和浏览器验证范围。

## 14. 反模式

1. 用大banner、插画、emoji、玻璃拟态、渐变或卡片重投影替代信息组织。
2. 将所有按钮做成高饱和彩色胶囊，或每张卡加彩色装饰条。
3. 复制来源卡片数量、路径、固定日期粒度、分页大小、阈值与指标公式后称为通用设计。
4. 把色槽存在当成组件已实现，把来源测试结果当成新项目测试结果。
5. 静态快照显示假刷新进度；复制失败仍提示成功；规划操作冒充实际执行。
6. 用分类色暗示危险或安全，以“大”直接推断可删、异常或浪费。
7. 隐藏分母、采集差额、权限或缺失数据；筛选后悄悄改变占比含义。
8. 为了“复刻”保留来源已知的键盘、归一化、浮层溢出或异步竞态问题。

## 15. 接入与维护

1. 填写[适配模板](ADOPTION_TEMPLATE.md)，确定业务边界与数据契约。
2. 映射主题和排版 token，实现页面骨架与基础组件。
3. 按分析问题选择可选图表，明确状态作用范围、容量与溢出行为。
4. 实现真实数据、错误恢复、键盘与主题切换，不用静态样例替代业务验收。
5. 完成实际浏览器测试，并在项目文档区分“规范/默认/实现/实测/未验证”。
6. 修改公共参数时同步本文、JSON和适配说明；纯文档更新检查JSON、链接与空白即可，不重跑业务采集。

通用核心的破坏性变化提升主版本；新增可选模式提升次版本；澄清和错误修正提升补丁版本。目标项目记录采用的版本和本地覆盖项。
